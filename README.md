# University Projects - КНУ имени Тараса Шевченко

Этот репозиторий содержит коллекцию учебных проектов, лабораторных и практических работ, выполненных за время обучения на факультете информационных технологий (ФИТ) по специальности "Инженерия программного обеспечения".

## Структура репозитория

Все работы разделены по курсам и дисциплинам для удобной навигации:

*   **/3_course**
    *   `/Frontend` - лабораторные работы по фронтенд-разработке.
    *   `/Software_Architecture` - проекты с реализацией паттернов проектирования GoF и принципов SOLID.
*   **/2_course**
    *   `/Web_Django` - разработка веб-приложений на Python.
    *   `/CSharp_NET` - разработка на C# с использованием ASP.NET Core MVC и Entity Framework.
    *   `/Java_Spring` - проекты на Java.

## Основной стек технологий

В рамках выполнения университетских заданий применяются следующие технологии:
*   **Языки программирования:** C#, Java, Python, JavaScript.
*   **Фреймворки:** .NET, ASP.NET Core, Spring Boot, Django.
*   **Базы данных:** SQL Server, MySQL, MongoDB, Redis.
