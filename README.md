# University Projects - КНУ імені Тараса Шевченка

Цей репозиторій містить колекцію навчальних проєктів, лабораторних та практичних робіт, виконаних під час навчання на факультеті інформаційних технологій (ФІТ) за спеціальністю "Інженерія програмного забезпечення".

## Структура репозиторію

Роботи структуровані за курсами та відповідними дисциплінами:

### 3 курс

- Операційні системи
- Сучасні технології системного програмування
- Захист програм і даних
- Комп'ютерне моделювання процесів
- Соціально-політичні студії
- Кросплатформне програмування 
- Розробник фронтенду програмних систем

### 2 курс

- CI/CD
- Об'єктно-орієнтоване конструювання програм
